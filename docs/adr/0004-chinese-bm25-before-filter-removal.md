# 中文词命中先于硬过滤下线

固定槽位引擎与词典交集硬过滤暂不删除。先重建 Milvus collection 使用中文分词器，让中文 BM25 真正生效；之后按记忆类型逐个下线硬过滤，每类下线都要有评测支撑。

理由：实测 mem0 2.2.1 的 BM25 只对英文与型号词命中，中文查询的关键词分为零；entity matching 依赖英文模型，对中文垂类没有收益。照原计划删掉硬过滤，中文领域词召回会退化成纯语义。实体匹配不能作为中文方案的依据。

垂类词表随之降级：先做抽取 prompt 的提示与类型 metadata 标签，不承担检索期过滤；是否需要检索期过滤交给评测决定，不另起一套硬过滤绕开这个决定。
