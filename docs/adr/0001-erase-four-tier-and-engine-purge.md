# 擦除的对外口径与引擎侧清理护栏

Thinkback 的擦除承诺分四档对外声明：不可召回、逻辑删除、物理擦除、备份过期。前两档由服务保证，第三档在单副本部署下成立，第四档目前没有机制，不对外宣称。

Mem0 的公开 CRUD 不清理它的 history 与 messages 表，`delete` 还会追加保留旧值的历史行。我们保留对该 SQLite 的定向删除，因为关掉 history 持久化会让 mem0 失去"最近对话作为抽取上下文"的能力。代价是绑定 mem0 内部表结构，因此固定 mem0 版本为 2.2.1，表结构或列名对不上时必须 fail-visible 并让操作失败，不允许静默跳过。

单副本是当前的发布边界，"本 pod" 即"全部"。多副本开放前，引擎侧历史必须先外置，否则一次擦除只能清到当前副本。
