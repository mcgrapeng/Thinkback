## Decisions Made
| Decision | Rationale |
|----------|-----------|
| 不修改业务实现，仅写审计/研究/计划产物 | 用户请求分析；当前分支已有未提交改动，需避免覆盖用户工作 |
| 以当前工作树为准，不以 README 宣称代替源码证据 | 分支为 refactor/memory-architecture-rewrite，文档与实现可能漂移 |
| 严重问题必须有具体输入/时序/配置触发路径 | 避免把架构偏好或模糊担忧误报为严重 bug |
| 外部比较优先官方文档、源码、协议，不用二手榜单 | 主流项目变化快，且功能名义相同不代表语义相同 |
| 负载按多租户、多进程、企业助手生产接入评估 | 这是用户明确目标，也是 README 的公开定位；另注明实测缺口 |
| 插件化优先采用服务/sidecar + 协议适配，不先做进程内通用库 | 任意语言助手需要网络契约；当前 Mem0 全局补丁也不适合直接嵌入 |
| 不先增加图数据库、复杂 reranker 或新框架 | 当前主要问题是安全、删除/写入一致性、召回逻辑和类型契约，新增基础设施不能修复 |
